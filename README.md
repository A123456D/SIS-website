# SIS — Systems Integration Specialists

Marketing site for SIS: solar backup, home automation, home theatre, CCTV, hybrid power, and MikroTik rural connectivity.

## Setup

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run test:pip` — Pip assistant knowledge/nav checks
